# Evidence Directory

Store only sanitized, repository-safe project evidence here.

Allowed examples:
- synthetic telemetry fixtures;
- capability matrices;
- redacted/sanitized timing summaries;
- test reports without local identifiers;
- resource measurements with generic host descriptions.

Do not commit real rollout JSONL, prompts, source code captured from user projects, raw tool output, secrets, account identifiers, local usernames/machine names, or absolute private paths.
